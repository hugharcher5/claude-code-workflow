# Model recommendation

Default model: Sonnet 5. Use it for routine edits, formatting, short research, ordinary notes, and simple code without comment.

Recommend Opus 5 only for:

- difficult architecture with meaningful trade-offs
- high-stakes decisions
- security or privacy design
- stubborn, multi-system debugging
- large builds requiring long-horizon reasoning
- a courtroom Judge verdict, when the decision warrants it

When one of these applies, say exactly:

`I would use Opus 5 for this.`

Then one plain-language sentence on why, and wait — do not proceed as Opus, and do not claim to have switched models unless the surface actually confirms a switch. If Opus 5 is unavailable on the account, say so and continue with the best available model.

Recommend once per task, not on every turn of the same task.
