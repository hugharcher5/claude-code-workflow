# When to read what

Quick index for "read the kit before answering" moments, per the global rule in `~/.claude/CLAUDE.md`: *for old personal work, read the kit journal and memory index first.*

- Starting on old/unfamiliar personal work → read `compiled/journal.md` (recent) then `compiled/MEMORY.md` (index) first.
- Before trusting anything just compiled → confirm it passed `scripts/lint_memory.py` and the user accepted the diff.
- Before repeating a past correction → check `compiled/corrections.md`.
- Before a frontend/design task → load `.claude/skills/ui-ux-pro-max/`.
- Before writing user-facing prose → apply `.claude/skills/humanizer/`, within the 75-word cap unless released.
- Before a spend/hiring/firing/product/keep-kill decision → offer courtroom (`.claude/skills/courtroom-mode/`).
